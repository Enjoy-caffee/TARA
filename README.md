# Tara's Sweet Showcase

Website Menu لكافيه "Tara" المختص بالكوكيز  

الهدف: عرض المنيو بشكل احترافي (Display Only) بدون طلبات أونلاين  

🎨 الهوية البصرية:

- الألوان: Baby Blue + Pastel Pink + Soft Green (مستوحاة من اللوغو والمكان)  

- الخطوط: Rounded Sans Serif ودية وواضحة  

- الصور: مزيج بين أيقونات مرسومة وصور حقيقية من المكان  

🖱️ تجربة المستخدم (UI/UX Pro Max):

- تصميم متجاوب (Mobile + Desktop)  

- **صفحة واحدة (Single Page)** مع Scroll سلس للأقسام  

- Navigation واضح بأربع أقسام رئيسية:  

  1. Cookies 🍪  

  2. Cold Drinks 🧊  

  3. Hot Drinks ☕  

  4. Mojito 🍹  

- كل منتج يظهر بشكل Card يحتوي على: صورة المنتج + اسمه + سعره (بدون وصف)  

- Call to Action: "Visit Us" مع موقع الكافيه وروابط التواصل الاجتماعي  

⚡ اللمسات الإضافية:

- Animations ناعمة عند دخول العناصر (Fade + Slide)  

- Footer احترافي مع روابط Instagram و WhatsApp  

- شعار "Tara" بارز في الـ Header مع Strawberry Icon  

- اللغة: عربية فقط مع دعم كامل للـ RTL  

- الأسلوب: Minimal Design نظيف وبسيط بدون ازدحام بصري  

Footer احترافي لكافيه "Tara"  

📌 المواصفات:

- خلفية بلون Baby Blue أو Pastel Pink ناعم  

- أيقونات واضحة (Minimal Flat Icons)  

- محتوى مرتب بثلاثة أعمدة:  

1. **تواصل معنا**  

   - أيقونة 📍 مع رابط Google Maps لموقع الكافيه  

   - أيقونة 📞 مع رقم الهاتف  

   - أيقونة ✉️ مع البريد الإلكتروني  

2. **تابعنا**  

   - أيقونة Instagram مع رابط الحساب الرسمي  

   - أيقونة WhatsApp مع رابط المحادثة المباشرة  

3. **الهوية**  

   - شعار "Tara" صغير في المنتصف  

   - عبارة قصيرة: "One bite is never enough"  

⚡ اللمسات الإضافية:

- دعم كامل للـ RTL  

- Hover Effect بسيط على الأيقونات (تغيير لون عند المرور)
